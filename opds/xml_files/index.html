கட்டற்ற தமிழ் மின்னூல்கள்   OPDS 1.2 Feed

இத்தளம் FreeTamilEbooks.com தளத்தின் மின்னூல்களை OPDS (Open Publication Distribution System) வடிவில் வழங்குகிறது. Moon+ Reader, FBReader, KOReader, Thorium போன்ற மின்வாசிப்பு செயலிகளில் இந்த முகவரியைச் சேர்த்து நேரடியாகத் தமிழ் மின்னூல்களைத் தேடிப் பதிவிறக்கலாம்.

📱 மின்வாசிப்புச் செயலிகளில் சேர்க்கும் முறை

  1. உங்கள் மொபைல் அல்லது கணினியில் உள்ள மின்வாசிப்புச் செயலியைத் திறக்கவும் (எ.கா. Moon+ Reader, FBReader, KOReader, Thorium).
  2. Net Library அல்லது OPDS Catalogs பகுதிக்குச் செல்லவும்.
  3. Add OPDS Catalog (புதிய OPDS பட்டியல் சேர்) என்பதைத் தேர்வு செய்யவும்.
  4. பெயர்: Free Tamil Ebooks என இடவும்.
  5. முகவரி (URL): https://kaniyamfoundation.github.io/FTE_opds_catalog/index.xml (அல்லது https://catalog.freetamilebooks.com/index.xml) என உள்ளிட்டு சேமிக்கவும்.
